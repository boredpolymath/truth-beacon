Apple macOS Gatekeeper

Opening on macOS

macOS releases are cryptographically signed with an official Apple Developer ID Application certificate. If Gatekeeper requests confirmation on first launch, right-click TruthBeacon.app, select Open, and click Open in the dialog. Or run xattr -cr /Applications/TruthBeacon.app.

Microsoft Windows Defender

Windows SmartScreen Prompt

When launching the installer or portable EXE, Windows SmartScreen may show an unrecognised app alert because the binary is not signed with an enterprise EV certificate. Click More info, then choose Run anyway. You can verify the SHA-256 hash first.

Linux Permissions

Linux AppImage Execution

After downloading the AppImage, grant execution permissions: chmod +x TruthBeacon_0.3.1_amd64.AppImage. On Ubuntu 22.04+, ensure libfuse2 is installed: sudo apt install libfuse2.

Zero Trust Principles

Local-First Defense Architecture

Unlike commercial security software that uploads your chats or telemetry to proprietary cloud servers, TruthBeacon runs 100% locally.

🛡️

100% Offline & Private

Zero external API calls, zero cloud telemetry, and zero tracking beacons. All threat scanning, perceptual DCT hashing, and audit log retention occurs exclusively on your machine.

🔐

Domain-Bound AES-256-GCM Vault

Authenticated encryption strictly bound to application domain AAD (TruthBeacon:EncryptedVault:v1) with Argon2id derivation, Zeroize-on-drop hygiene, and strict owner-only POSIX permissions.

🗄️

Forensic SQLite Quarantine

Pre-flight SQLite integrity gates (PRAGMA integrity_check) preserve corrupt databases and WAL frames into timestamped archives without data loss, alongside non-blocking online backups.

🧵

Rayon Worker Pool & UTR #39

Dedicated Rayon pool offloading for DCT & 3-keyframe animated avatar sampling, paired with Unicode Technical Report #39 confusable canonical skeletons for unmasking sneaky homoglyphs.

⚡

Multi-Guild Gateway & Anti-Replay

Multi-guild connection manager with shared token deduplication, jittered exponential backoff, Opcode 6 session resumption, and replay-immune authoritative backend moderation.

🔄

Cryptographic Auto-Updater & Sandboxing

Ed25519 Minisign signed updates across macOS, Windows, and Linux powered by Tauri 2, with tightly scoped native capabilities and hardened content security policies.
