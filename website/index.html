Apple macOS Gatekeeper

Opening on macOS

macOS releases are cryptographically signed with an official Apple Developer ID Application certificate. If Gatekeeper requests confirmation on first launch, right-click TruthBeacon.app, select Open, and click Open in the dialog. Or run xattr -cr /Applications/TruthBeacon.app.

Microsoft Windows Defender

Windows SmartScreen Prompt

When launching the installer or portable EXE, Windows SmartScreen may show an unrecognised app alert because the binary is not signed with an enterprise EV certificate. Click More info, then choose Run anyway. You can verify the SHA-256 hash first.

Linux Permissions

Linux AppImage Execution

After downloading the AppImage, grant execution permissions: chmod +x TruthBeacon_0.1.2_amd64.AppImage. On Ubuntu 22.04+, ensure libfuse2 is installed: sudo apt install libfuse2.

Zero Trust Principles

Local-First Defense Architecture

Unlike commercial security software that uploads your chats or telemetry to proprietary cloud servers, TruthBeacon runs 100% locally.

🛡️

100% Offline & Private

No external API calls, no third-party telemetry, no analytics beacons. All threat scanning, perceptual DCT hashing, and log retention occurs exclusively on your machine.

📦

Zero-npm Webview

Zero dependency on npm runtime blobs or Node.js runtime vulnerabilities. Built with standard semantic HTML, CSS, and Tauri 2 OS webviews for absolute supply-chain integrity.

🦀

Native Rust Performance

Powered by a multi-threaded Rust daemon executing homoglyph analysis, DCT frequency hashing, and fuzzy Levenshtein comparisons with sub-millisecond response times.

📜

Open Source & Auditable

Dual-licensed under MIT and Apache-2.0. Complete test suites with 100% test pass rate, license compliance audits, and adversarial red-team simulations verifiable on GitHub.
